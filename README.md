# Bad Mojo Redux Steam display mod

This mod is for the **English Steam version of Bad Mojo Redux** on Windows. It
enlarges the game image without the black bars at the top and bottom and keeps
the desktop at its current resolution. Some movies have their own black bars;
the mod does not remove those from the movie image.

The mod runs the game in a window and uses [Magpie](https://github.com/Blinue/Magpie)
to scale it to fullscreen. The game may appear in a window for several seconds
before Magpie takes over. This delay is expected.

Cropping the game's top and bottom bars also hides its original lives display.
The mod adds a lives overlay to the enlarged game image. Press **F9** to toggle
the overlay. The overlay starts hidden and can briefly appear when the number
of lives changes.

The mod also skips the opening company logo movies on the supported English
Steam version. In-game movies remain available.

All mod code and scripts in this repository were generated by OpenAI Codex
under the project owner's direction. The original Bad Mojo Redux game and
Magpie are separate works and are not included in this repository.

## Requirements

- The English Steam version of Bad Mojo Redux, installed and able to launch
  normally before applying the mod.
- Windows PowerShell and the files in this repository.
- An internet connection for the first installation, unless Magpie x64 is
  already in the game folder. The installer obtains the latest stable x64 ZIP
  from [Magpie's official releases](https://github.com/Blinue/Magpie/releases/latest).
  Version 0.12.1 was used for the game's confirmed runtime checks; newer
  releases are accepted but have not been checked with this mod.

## Install

1. Close Bad Mojo Redux and Magpie. Download this repository as a ZIP and
   extract it. Copy the **contents** of the extracted folder into the Steam
   `BadMojo` game folder. The mod's replacement launcher is inside `Payload/`,
   so this copy does not overwrite the game's original `launcher.exe`.
2. If you already have Magpie x64, place it in `<game folder>\Magpie\` so that
   `<game folder>\Magpie\Magpie.exe` exists. The installer keeps that copy,
   including newer versions. Otherwise, it downloads and extracts the latest
   stable x64 release from Magpie's official GitHub page when you run it.
   Magpie is not included in this repository.
3. Double-click `<game folder>\Install.cmd`. If Windows denies access to the
   Steam folder, run `Install.cmd` as administrator. Before the installer
   replaces the game launcher, the game folder looks like this (with Magpie
   present if you supplied it yourself):

   ```text
   BadMojo\
   ├─ BADMOJO.EXE
   ├─ launcher.exe                 (original, until installation)
   ├─ README.md
   ├─ LICENSE
   ├─ Install.cmd
   ├─ Install-BadMojoMod.ps1
   ├─ Uninstall.cmd
   ├─ Uninstall-BadMojoMod.ps1
   └─ Payload\launcher.exe         (mod replacement, not installed yet)
   ```

4. Wait for `Bad Mojo Redux mod installed.` The installer verifies the game,
   mod files, and resource paths, obtains Magpie if needed, then saves the
   original `launcher.exe` as
   `launcher-original.exe`. It leaves `BADMOJO.EXE` and `qthook.dll` unchanged.
5. Start the game using Steam's **Play** button. Magpie starts automatically
   after the game window responds; wait for the fullscreen image. Press **F9**
   to show or hide the lives overlay.

The installer stops before replacing the launcher if the game files do not
match the supported English Steam version or a resource path exceeds the
game's 50-byte limit. It does not use a virtual drive or junction. Saves stay
in the game's `SAVE` folder.

## Uninstall

Close Bad Mojo Redux and Magpie, then double-click `<game folder>\Uninstall.cmd`.
If Windows denies access to the Steam folder, run it as administrator. It
restores the original `launcher.exe`, removes the Mod's files and its own
uninstaller files, and leaves `BadMojoMod-uninstall.log` in the game folder.
The `SAVE` directory and everything inside it are explicitly protected and
never removed by the uninstaller. Magpie downloaded by this Mod's installer is
removed. A Magpie copy you placed yourself is preserved; only the Mod's Magpie
profile is removed from it. If the package contains unexpected files, or the
launcher backup does not match the supported original, the uninstaller stops
and records the reason in the log.
